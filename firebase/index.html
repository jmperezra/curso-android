Introducción

 

Instalación

Para instalar Firebase se necesitan las dependencias propias a la librería, las de firebase y las de Google Services. Por tanto, para usar firebase debemos añadir:

  1. Plugin de Google Services.
  2. Librería de Firebase.

1. Google Services

En el fichero libs.versions.toml que se encuentra en la carpeta gradle hay que añadir en la sección de plugins la siguiente línea:

[versions]
googleServices = "4.4.2"

[plugins]
google-services = { id = "com.google.gms.google-services", version.ref = "googleServices" }

Las secciones [versions] y [plugins] seguramente estén ya en el fichero junto con otras librerías.

Ahora hacemos referencia a esta librería en el fichero build.gradle.kts a nivel de aplicación.

plugins {
    alias(libs.plugins.google.services) apply false
}

Al igual que pasaba con el fichero libs.versions.toml seguramente aquí tengas más librerías, en ese caso símplemente habrá que añadir la línea de google.services.

Por último, hacemos referencia a la librería en el fichero build.gradle.kts debajo de la carpeta app/

plugins {
    alias(libs.plugins.google.services)
}

2. Firebase

Una vez añadido el plugin de google-services, pasamos a añadir las librerías de Firebase.

Vamos al fichero libs.versions.toml y añadimos estas líneas:

[versions]
firebaseBom = "33.8.0"

[libraries]
firebaseBom = { module = "com.google.firebase:firebase-bom", version.ref = "firebaseBom" }

Para Firebase usamos la opción 'Bom' (Bill of material), con esto tenemos el beneficio de tener siempre la misma versión para todos los productos que usemos de Firebase. Así será más sencillo ir subiendo de versión.

Ahora lo añadimos al fichero build.gradle.kts a nivel de app/:

dependencies {
    //Firebase
    implementation(project.dependencies.platform(libs.firebaseBom))
}

Como puedes ver, al usar Bom debemos añadir la referencia a la librería a través de platform.

Ya está instalado Firebase.
